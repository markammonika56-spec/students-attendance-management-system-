# Student Attendance Management System

A simple and responsive web-based Student Attendance Management System developed using HTML, CSS, and JavaScript.

## 📌 Project Overview

The Student Attendance Management System is a mini web project designed to make student attendance tracking simple and easy.

It allows users to add students, mark their attendance, search for students, and automatically calculate attendance percentage.

## ✨ Features

- ➕ Add new students
- 🔍 Search students by name or roll number
- ✅ Mark students as Present
- ❌ Mark students as Absent
- 📊 Automatically calculate attendance percentage
- 🗑️ Delete student records
- 💾 Save data using browser Local Storage
- 📱 Responsive design for mobile and desktop
- 🌐 Deployed using GitHub Pages

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- GitHub Pages

## ⚙️ How It Works

1. Enter the student's roll number and name.
2. Click the **Add Student** button.
3. Use **Present** or **Absent** buttons to record attendance.
4. The system automatically calculates the attendance percentage.
5. Use the search box to find a particular student.
6. Student data is stored in the browser using Local Storage.

## 📊 Attendance Calculation

Attendance percentage is calculated using:

**Attendance % = (Present Classes / Total Classes) × 100**
